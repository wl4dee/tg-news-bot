Треба додати джерело: **$ARGUMENTS**

Джерела живуть у Google Doc «02 — Джерела», не в коді. Твоя робота — перевірити,
що джерело робоче, і видати готовий рядок, який користувач вставить у документ
із телефону.

## 1. Визнач тип

- Починається з `@` або схоже на ім'я ТГ-каналу → `tg`
- URL → `rss`

## 2. Перевір, що воно живе

**Для `rss`:**

```bash
curl -sS -L -o /tmp/feed.xml -w "HTTP %{http_code}  %{size_download} bytes  %{content_type}\n" --max-time 20 "<URL>"
```

Далі переконайся, що це справді фід, а не сторінка помилки:

```bash
python -c "import feedparser,sys; d=feedparser.parse(open('/tmp/feed.xml','rb').read()); print('bozo:',d.bozo); print('entries:',len(d.entries)); print('title:',d.feed.get('title')); [print(' -',e.get('title','?')[:80]) for e in d.entries[:3]]"
```

Приймається тільки якщо: HTTP 200 **і** `entries > 0` **і** заголовки виглядають
як новини. `bozo: 1` саме по собі не вирок — багато робочих фідів невалідні
формально, дивись на `entries`.

**Для `tg`:**

```bash
curl -sS -L --max-time 20 "https://t.me/s/<канал>" | grep -c "tgme_widget_message "
```

Нуль означає, що канал приватний або не має вебпрев'ю — тоді його брати не можна,
потрібен Telethon (відкладено до v2). Так і скажи.

## 3. Рубрика і вага

Рубрика — одна з наявних у документі: `крипта`, `ринки`, `техно`, `Україна`, `Київ`.
Нову рубрику вигадуй тільки якщо користувач попросив явно — інакше для неї не буде
рядка `limit`, і вона обійде баланс рубрик.

Вага за шкалою з документа: `3` — першоджерело (регулятор, суд, біржа, сама компанія);
`2` — нормальне ЗМІ; `1` — сигнал, потрібне підтвердження.
Якщо вагу не назвали — запропонуй свою і поясни одним реченням чому.

## 4. Віддай результат

Готовий рядок і куди його вставити:

```
rss | https://... | крипта | 2
```

Вкажи, під який заголовок-секцію документа він логічно лягає. Сам документ ти
редагувати не можеш — це робить користувач. Не пропонуй додати джерело в код.

Якщо фід не пройшов перевірку — скажи прямо, з кодом відповіді, і не давай рядок.
