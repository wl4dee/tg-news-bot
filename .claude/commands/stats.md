Порахуй, наскільки оцінювач із документа 01 збігається з реальними рішеннями
людини, і скажи, чи треба рухати поріг.

## Дані

`state.json`, масив `stats`. Кожен запис: `{score, rubric, decision, ts}`,
де `decision` — `pub` або `rej`. Масив не чиститься ніколи, тому це вся історія.

## Порахуй

```bash
python - <<'PY'
import json, collections
s = json.load(open('state.json')).get('stats', [])
if not s:
    raise SystemExit('stats порожній — ще не було жодного рішення по кнопці')

print(f'усього рішень: {len(s)}\n')

print('за бакетами score:')
print(f'{"score":>6} {"pub":>5} {"rej":>5} {"конверсія":>10}')
b = collections.defaultdict(lambda: [0, 0])
for r in s:
    b[r['score']][0 if r['decision'] == 'pub' else 1] += 1
for score in sorted(b):
    pub, rej = b[score]
    print(f'{score:>6} {pub:>5} {rej:>5} {pub/(pub+rej):>9.0%}')

print('\nза рубриками:')
print(f'{"рубрика":>10} {"pub":>5} {"rej":>5} {"конверсія":>10} {"сер.score":>10}')
r_ = collections.defaultdict(lambda: [0, 0, []])
for r in s:
    e = r_[r['rubric']]
    e[0 if r['decision'] == 'pub' else 1] += 1
    e[2].append(r['score'])
for rub in sorted(r_):
    pub, rej, sc = r_[rub]
    print(f'{rub:>10} {pub:>5} {rej:>5} {pub/(pub+rej):>9.0%} {sum(sc)/len(sc):>10.1f}')
PY
```

## Інтерпретуй

Питання, на яке відповідає ця таблиця: **де проходить реальний поріг користувача?**

- Бакет, у якому конверсія падає нижче ~50%, і є фактичним порогом. Якщо це, скажімо,
  7, а документ 01 велить відсікати `< 6` — значить бакет 6 генерується марно,
  і поріг у документі варто підняти до 7.
- Конверсія 100% у високих бакетах і нуль у низьких означає, що оцінювач працює.
  Рівна конверсія всюди означає, що `score` нічого не передбачає — тоді проблема
  в критеріях документа 01, а не в порозі.
- Рубрика з низькою конверсією і високим середнім score — джерела в ній шумлять
  або ліміт рубрики завеликий.

Дай висновок одним абзацом і **конкретну правку в документ 01 або 02**, якщо вона
напрошується. Менш ніж на 20 рішеннях висновків не роби — так і скажи, що вибірка
замала.
