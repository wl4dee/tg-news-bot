# Стиль коду

## Загальне

- Python 3.11, стандартна бібліотека + `requests`, `feedparser`, `beautifulsoup4`.
  Нових залежностей не додаємо без причини, яку можна назвати вголос.
- Кожен модуль у `bot/` — самодостатній: імпортується без побічних ефектів,
  запускається як `python -m bot.<module>` для локальної перевірки, де це має сенс.
- Ніяких класів заради класів. Функції й `dict`. Це скрипт на 30 хвилин крону,
  а не сервіс.
- Типи в сигнатурах публічних функцій — так. Повний mypy — ні.

## Логування

`logging`, не `print` (виняток — DRY_RUN-вивід, який навмисно людський).
Формат заданий у `bot/main.py`, модулі просто беруть `logging.getLogger(__name__)`.

| Рівень | Коли |
|---|---|
| `info` | етапи прогону, скільки чого зібрано, що опубліковано |
| `warning` | мертве джерело, пропущений айтем, `429` |
| `error` | нерозібраний JSON, збій Telegram/KV, який не валить прогін |

**Ніколи не логуй значення env-змінних.** Ні цілком, ні «перші 6 символів».
Токен у публічному Actions-логу — це скомпрометований токен.

## Помилки

Мережа падає постійно, і це нормальний режим роботи, а не виняток.

- Одне джерело впало → `warning` + `continue`. Прогін триває.
- Gemini повернув сміття → `error` + `continue`. Прогін триває.
- Telegram не прийняв чернетку → `error` + `continue`. Решта чернеток іде.
- Немає секрету / конфіг у `config/` не читається → **падати одразу**, з людським
  повідомленням українською, у якому написано, що саме зробити.

Правило просте: падає тільки те, без чого прогін безглуздий. Решта деградує.

## Робота з часом

Усе в UTC, ISO-8601 із `Z`. Одна функція `state.now_iso()` — і більше ніде
`datetime.now()` без tz. Порівняння дат — через `state.parse_iso()`.

## Мережа

- Кожен `requests` виклик має `timeout`. Без винятків.
- Один спільний `requests.Session` на прогін, із браузерним UA.
- `feedparser.parse()` не отримує URL — тільки байти, які ми вже завантажили
  самі з таймаутом. Інакше таймаут неконтрольований.

## Секрети

Читаються рівно в одному місці — `bot/config.py::env()`. Модулі беруть їх звідти.
Ніяких `os.environ[...]` розкиданих по файлах: так легше довести, що токен
нікуди не тече.

## Мова

Коментарі, логи й повідомлення про помилки — українською. Назви змінних,
функцій і полів JSON — англійською. Рубрики — українською, бо вони приходять
з документа й ідуть у хештег.
